# EasyCab AR

Просмотр шкафа из EasyCab в дополненной реальности: модель встаёт на пол в масштабе 1:1.

Адрес: https://vertexx79-bit.github.io/easycab-ar/

Шкаф передаётся в ссылке (после `#`). Без параметров открывается пример.
Работает в Chrome на Android с поддержкой Google ARCore и в Safari на iPhone.

Страница собирается из `shkaf.html` скриптом `ar/build.js`, поэтому модель всегда совпадает с редактором.
